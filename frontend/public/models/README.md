# 3D Avatar Models for Veyra (Indian Sign Language)

You can place a custom 3D rigged character file here named:
```
frontend/public/models/avatar.glb
```

## Recommended Free Sources for Humanoid Rigged 3D Avatars:
1. **Ready Player Me:**
   - Go to [https://readyplayer.me](https://readyplayer.me)
   - Create your avatar (takes 30 seconds).
   - Click **Download .glb** and save it as `avatar.glb` in this folder.
   - It comes with standard Mixamo humanoid bones including all individual finger joints!

2. **Mixamo (Adobe):**
   - Go to [https://www.mixamo.com](https://www.mixamo.com)
   - Select characters like **"X Bot"** or **"Y Bot"**.
   - Download as FBX/GLB.

3. **Built-in Fallback:**
   If `avatar.glb` is not present, Veyra automatically uses its built-in articulated anatomical 3D sign rig with 3-joint bending fingers and high-visibility contrast!
